# NRF240l-STM32-Flight-Controller
Custom RC aircraft control system using an Arduino Nano transmitter, STM32F103C8T6 flight controller, nRF24L01+ telemetry link, MPU IMU, BMP180 barometer, battery/current sensing, direct PWM servo/ESC control, configurable aircraft mixing, and a custom 128×64 OLED TX interface.
